# ADPKD-ECS — Agent instructions

This repository is a **program** (cannabis / ECS × ADPKD), not a lab. **Study 1** (atlas kill) uses the SEAL files at repo root. **Study 2** lives in [`studies/cannabis-safety/`](studies/cannabis-safety/). **Study 3** (docking) stays in [`EXPLORE.md`](EXPLORE.md) until a new sealed protocol after study 1 Decide.

- **Science Superpowers** drives the agent. Follow the user plugin at `~/.cursor/plugins/local/science-superpowers`. See [`docs/SUPERPOWERS.md`](docs/SUPERPOWERS.md).
- **SEAL** is the study contract. Each study has its own `QUESTION.md`, `KILL.md`, `CLAIMS.md`, `PROTOCOL.md`, human Seal/Decide, OSF. Kernel: [`.seal/`](.seal/).
- Superpowers does **not** replace a named confound, a cheap kill, a claims ceiling, or a human gate. If a skill and a sealed SEAL file disagree, the sealed file wins.
- Do not open study 1 confirmatory outcome matrices until root `STATUS.md` records git seal **and** OSF **submit**.
- Do not crawl publisher PDFs through a library proxy. Paywalled PDFs are human TODOs (drop into the study folder).
- Do not start Pathways B–D (docking, dual ligands, ADMET, MQ1) from this tree until a **new** sealed protocol names them.
- Do not mix study 1 and study 2 claims. A *CNR1* gate does not license CBD advice; a label map does not pass Gate A.
- ecs-lab (`../ecs-lab`) is a Scout lab. Do not harvest literature into this repo as a Scout dump. Study 2 is a **sealed** evidence map, not a nightly crawl. Do not copy Scout chats’ “ignore Superpowers” rule here.

Study 1 Unit 00 (inventory, no expression-vs-CNR1) waits until root `STATUS.md` has git seal **and** OSF URL. Until OSF: specify leftovers only, no count load. Study 2 confirmatory units wait on that study’s OSF URL. Study 2 must not load GEO counts.

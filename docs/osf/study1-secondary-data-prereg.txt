OSF FIELD: Description
OSF PROMPT: Write a detailed description of your research project, including its purpose and any expected outcomes. This should give readers a comprehensive overview of your work.
ANSWER:
This registration is study 1 of the ADPKD-ECS program (https://github.com/cauld/adpkd-ecs): a pre-specified secondary analysis of public kidney snRNA-seq atlases. It is a kill test of a published computational claim about CNR1, not a treatment study and not a chemistry campaign.

Purpose. Hinden et al. (Mol Med 2026) reported disease-associated CNR1 upregulation with enrichment in proximal-tubule / failed-repair epithelium, using GSE185948 (ADPKD) and a DKD comparison. Their primary snRNA statistic averaged CNR1 across all cell types per sample, which is vulnerable to changing cell-type composition. A 2026 source briefing treated PT-restricted, ADPKD-specific CNR1 as a license for later CB1-antagonist chemistry. This study audits that map under a frozen protocol (git SHA db44b3086ae8c4d640dc40f44945bcef27ffe6bc): define PT / failed-repair without using CNR1 as a marker; test CNR1 inside that state; check composition; and, only if ADPKD within-PT induction is supported, test whether the same within-PT upshift appears in diabetic kidney disease (GSE195460).

Data. Cross-sectional public GEO snRNA-seq: GSE185948 (Muto et al. 2022; ADPKD vs control) and GSE195460 Cell Ranger RNA matrices (Wilson et al. 2022; DKD vs control). Count matrices will not be loaded until this OSF URL is recorded. A sibling registration (study 2) maps cannabis/CBD/tolvaptan labels and trials; it is a different question and must not be mixed with these GEO hypotheses.

Expected outcomes. Human-owned gates (detectability; within-PT ADPKD vs control or a map-only fallback; composition wall; DKD specificity) will either pass or fail as specified in the sealed KILL.md. A clean negative is a complete result: the briefing’s PT-restricted, disease-induced CNR1 story would be reported as not supported in these atlases. Public donor n is a large-effect test only; a fail does not prove CNR1 is unchanged. Passing does not license cannabis or CB1-drug advice, a claim that CB1 causes cysts, or docking/chemistry. Study 3 (docking) requires a new sealed protocol after Decide.

ITEM 3. Research questions
ANSWER:
RQ1. After freezing proximal-tubule / failed-repair epithelium without CNR1 as a marker, is CNR1 higher in ADPKD than in control inside that state in GSE185948, after a composition check?
RQ2. Is that within-PT induction absent in diabetic kidney disease under the same freeze (GSE195460)?
(One-sentence form: After freezing proximal-tubule / failed-repair epithelium without CNR1 as a marker, is CNR1 higher in ADPKD than in control inside that state in GSE185948 (after a composition check), and is that within-PT induction absent in diabetic kidney disease under the same freeze (GSE195460)?)

ITEM 4. Hypotheses
ANSWER:
Framework: frequentist NHST / 95% CI on a pre-specified contrast. Human marks gates in KILL.md. Sole confirmatory gene: CNR1.

Gate C (detectability, ADPKD atlas):
  H0: Detection of CNR1 (count > 0) is < 1% of nuclei in the frozen PT / failed-repair object, or that object has n < 100.
  H1: Detection >= 1% and n >= 100.
  If C fails: do not run Gate A or Gate S as confirmatory localization / induction / specificity.
  Rationale: sparse dropout can make CNR1 “dark”; localization claims require a frozen PT object with enough detection.

Gate A1 (if Unit 00 finds >= 3 ADPKD and >= 3 control samples):
  H0: Within frozen PT / failed-repair only, 95% CI for mean CNR1 (ADPKD minus control) includes 0, or ADPKD is not higher.
  H1: CI excludes 0 and ADPKD mean is higher.
  Rationale: published claim (Hinden et al. Mol Med 2026) is disease-induced CNR1 in PT; their primary snRNA statistic averaged all cell types per sample (composition-vulnerable). This tests within-PT induction.

Gate A2 (only if A1 ineligible):
  H0: Within ADPKD samples, 95% CI for CNR1 (frozen PT minus other epithelium) includes 0, or PT is not higher.
  H1: CI excludes 0 and PT is higher.
  If A1 was eligible, A2 is descriptive only and cannot pass Gate A.
  Rationale: map-only localization if controls are insufficient; not disease-specific induction.

Gate S (only if C passed AND A1 passed AND >= 3 DKD and >= 3 control samples):
  H0_S (specificity NOT supported): within frozen DKD-atlas PT, 95% CI for CNR1 (DKD minus control) excludes 0 and DKD is higher.
  H1_S (specificity supported): that CI includes 0, OR DKD mean is not higher.
  C_S eligibility: same 1% / n>=100 detection on DKD PT object; if C_S fails, S is ineligible (not an S pass).
  S cannot pass or rescue Gate A.
  Rationale: named confound 3 — generic injury / DKD recapitulation.

Gate B (only if Gate A passed; cannot rescue an A fail):
  B1 (protocol): Gate A used the frozen PT object, not all nuclei. Fail if all cells were scored.
  B2 (if A1 ran): inside ADPKD PT, failed-repair vs non-injured PT; report 95% CI. Does not reverse A1. If failed-repair CNR1 is lower, do not claim restriction to failed-repair.
  B3 (diagnostic only): sample-level epithelial mean CNR1 vs p_PT; cannot pass A.

Named confounds: (1) composition; (2) constitutive PT marker; (3) generic injury (same upshift in DKD).

ITEM 12. Measured variable(s)
ANSWER:
Outcome (confirmatory): CNR1 counts. Estimator when n>=3 per group: sum raw counts per donor in contrast cells, drop donor x PT bins with <10 nuclei, log1p(CPM), Welch t on donor means. 95% CI is the pass metric. Wilcoxon rank-sum (nucleus-level) only if n<3 per group; then pass = two-sided p<0.05 AND Hodges-Lehmann in hypothesized direction; Cliff's delta reported, not the pass metric.
Grouping (categorical): disease label (ADPKD vs control; DKD vs control); frozen PT / failed-repair vs other epithelium.
Assignment-only (not the kill): PT identity LRP2, CUBN, SLC34A1, SLC13A3; injured/failed-repair VCAM1, HAVCR1, PROM1. Prefer author labels when present.
Other epithelium markers (substring, first match): SLC12A1, SLC12A3, AQP2, CALB1, SLC26A7.
Descriptive ECS panel (cannot pass A or S): CNR2, GPR55, FAAH, MGLL, NAPEPLD, DAGLA, DAGLB, TRPV1.
Must not use CNR1 or glycolysis genes HK2, PKM, LDHA to define PT.
Composition diagnostic B3: sample-level epithelial mean CNR1 vs p_PT (fraction PT among epithelial nuclei); cannot pass A.
No EFA/CFA scales.

ANSWER:
Fixed public n. Qualitative: n~8 vs 5 (or 5 vs 6) is below usual RNA-seq floors for modest fold changes. No post-hoc power after seeing CNR1. If underpowered, report CI and Decide table; do not switch to nucleus Wilcoxon after seeing A1 when n>=3.

ITEM 22. Inference criteria
ANSWER:
Human-owned pass/fail per KILL.md.
C: detection >=1% and n>=100.
A1: 95% CI excludes 0 and ADPKD higher; sole gene CNR1; PT object only.
A2: only if A1 ineligible; CI excludes 0 and PT higher.
S pass: DKD-control CI includes 0 OR DKD not higher.
S fail: CI excludes 0 and DKD higher.
Two-sided tests. No multiple-testing correction for the one confirmatory gene.
Decide table in KILL.md maps combinations to stop / map-only / induction +/- specificity. Docking is not licensed by this registration.
